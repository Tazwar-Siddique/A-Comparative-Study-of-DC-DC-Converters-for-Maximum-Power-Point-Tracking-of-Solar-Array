# A-Comparative-Study-of-DC-DC-Converters-for-Maximum-Power-Point-Tracking-of-Solar-Array
This is a project about a comparison of several DC-DC converters for MPPT of solar arrays. The study evaluates the efficiency, response time, and output ripple of each converter under varying irradiance and temperature conditions. The results of this project was presented as a poster at ICECIE 2024.
